# 渠道与版位

当前 APP 图片能力覆盖信息流、学习机、应用商店等渠道，但真实尺寸、字数、审核和压缩要求以维护者提供的正式规格为准。

`config/channel-placement-rules.json`是新任务版位配置的唯一来源。应用商店按维护者2026-09-14确认的清单提供5个平台、10个版位；配置卡先选平台，再选具体版位，并保留上游单图/双图/三图约束。其他渠道沿用原配置。

卡片展示每套张数、每张最终尺寸和压缩上限。荣耀竖版三图每套3张、每张1280×1920；未填写体积上限时沿用默认200KB，交付继续使用JPG。图片总数为文案数×套数×每套张数。

旧任务交付继续读取已保存的配置和清单，不用新任务版位表替换历史尺寸。该文件不是自动更新的渠道官方规范，后续调整以维护者提供的规格为准。

当前配置卡一次只能选择一个具体版位；下游仍读取`placements[]`，但正式保存结果的数组长度必须为1。
